# 指令管理产品需求文档

版本：V1.0  
日期：2026年10月22日  
产品：ANSU 安速货运管理系统  
适用模块：运单管理 → 海外中转单 → 指令管理  
用途：明确费用指令配置的功能范围、业务规则、交互和验收标准，供产品、设计、研发与测试评审。

## 1 产品定位与目标

指令管理统一维护海外仓作业所需的费用指令字典，包括费用名称、类型、计费单位、计费单价、成本单价、币种、启用状态及描述。暂存管理下单、指令详情新增费用时，可以选择启用的费用项目并带入默认配置，减少重复录入及费用口径差异。

本模块管理“可选择的费用项目”。例如，“拍照费”是一个字典项目；某票运单申请拍照3张形成的记录是业务指令实例，应在指令列表及其详情中处理。

本期目标：

- 按费用代码、费用类型和启用状态快速定位费用项目。
- 维护已有项目，使用停用控制后续是否可选。
- 记录每次有效修改及字段修改前后的内容。
- 按筛选结果或跨页勾选范围导出完整费用数据。
- 为暂存下单和指令费用维护提供一致的配置来源。

本文以当前本地页面为功能基线。“上线建议”和“待确认事项”用于说明未落定的要求，不代表当前页面已经实现。

## 2 使用场景与角色

### 2.1 核心场景

业务人员查询拍照、换箱、分拣等费用的单位、价格和币种，核对下单采用的费用口径。

配置维护人员调整费用单价或说明，保存后重新进入暂存下单，从目录读取最新配置。

某项服务暂停提供时，将项目设为停用。项目继续保留，支持查询、日志追溯和重新启用；后续新增费用时不再提供该项目。

维护人员导出筛选后的全部项目，或跨页勾选部分项目后导出，用于线下核对。

### 2.2 角色与权限

当前页面没有独立的模块权限校验。下表为上线建议，角色归属和授权范围需要评审确认。

| 建议角色 | 建议权限 | 需确认的约束 |
| --- | --- | --- |
| 业务使用人员 | 查询目录，查看获授权字段 | 成本是否可见，是否允许导出 |
| 费用配置维护人员 | 查询、编辑、启停、查看日志 | 业务指定可维护费用的人员 |
| 审核或管理人员 | 核对配置及变更记录，按授权导出 | 本期不引入单价修改审批流 |

上线后权限必须由服务端校验，隐藏按钮不能代替授权控制。当前原型日志操作人是固定展示值，上线后应记录实际登录身份。

## 3 功能范围

本期包含：页面入口与直接链接、组合查询与重置、列表与分页、本页全选和跨页勾选、编辑已有指令、启用与停用、单项目变更日志、CSV导出、显示列设置，以及向关联页面提供启用的费用目录。

当前页面不包含：新增或删除费用项目、费用导入、批量调价、批量启停、客户专属价格、阶梯计价、最低消费自动计算、税费计算及价格变更审批。描述中的“低消”等文字只是说明，不能视为系统已自动执行对应规则。

业务指令的批量下单、批量驳回、作业处理和运踪维护属于指令列表及详情，不在本模块重复建设。

## 4 入口与页面结构

### 4.1 导航规则

“海外中转单”子菜单顺序为：**暂存管理 → 指令列表 → 指令管理**。打开后侧栏高亮指令管理，顶部展示可关闭的同名页签；关闭后返回业务运单页面。

本地直接链接：`http://localhost:3000/A--a/#instruction-management`。直接进入时应展开海外中转单菜单组并显示本模块内容。

### 4.2 页面组成

页面依次为标题区、筛选区、列表和分页区。列表工具栏提供导出、已选数量、列设置；每行提供编辑及日志入口。编辑和日志使用弹窗承载。

沿用当前紫色主色、深色导航、浅色背景、白色卡片与圆角样式。列表横向滚动时右侧操作列固定，纵向滚动时表头固定。长文本截断展示，悬停可查看完整内容。

## 5 字段定义

| 字段 | 编辑规则 | 展示与校验 |
| --- | --- | --- |
| 费用ID | 系统字段，无编辑入口 | 用于记录与日志关联；非普通业务展示列 |
| 费用代码 | 只读 | 稳定业务标识，例如FY20260820024；支持模糊查询 |
| 费用名称 | 必填，可编辑 | 最多80字符；去除首尾空格，不允许仅空格 |
| 费用类型 | 必填，下拉选择 | 选项取初始及现有项目类型集合，本页不新增类型 |
| 计费单位 | 必填，可编辑 | 最多30字符；去除首尾空格；如张、箱、托、Per Pallet |
| 计费单价 | 必填，可编辑 | 非负有效数值，输入步长0.01，列表保留两位小数，允许0 |
| 成本单价 | 必填，可编辑 | 非负有效数值，输入步长0.01，列表保留两位小数，允许0 |
| 币种 | 下拉选择 | 美元USD、人民币CNY、欧元EUR、英镑GBP；列表显示中文名 |
| 状态 | 下拉选择 | 仅启用、停用；分别使用绿色与灰色标识 |
| 描述 | 选填，可编辑 | 最多500字符，保存时去除首尾空格，说明费用含义与作业要求 |

当前列名为“计费单价（元）”“成本单价（元）”，同时支持多币种。实际金额应按该行币种理解，不能因为列名带“元”就按人民币计算。上线建议改为“计费单价”“成本单价”，由币种列明确单位，文案变更需业务确认。

当前内置20个示例项目，初始计费单价为0、币种为USD、状态为启用，成本按项目配置。示例用于本地演示，不能直接视为已审批的生产价格。

## 6 功能与交互要求

### 6.1 查询与重置

筛选项为费用代码、费用类型和状态。代码去除首尾空格后进行不区分大小写的包含匹配；类型和状态精确匹配，“全部”或空值不限制结果。不同条件之间取交集。

修改筛选输入不立即刷新列表。点击查询或提交表单后应用条件，回到第1页并清空勾选。重置清空输入及已应用条件，恢复全部项目，返回第1页并清空勾选。

无匹配结果时展示“暂无符合条件的费用指令”、调整筛选提示和重置入口；总条数为0，导出不可用。

### 6.2 列表与分页

业务列默认全部显示，顺序为费用代码、名称、类型、单位、计费单价、成本单价、币种、状态、描述。无新增、删除或批量编辑按钮。

默认每页20条，可选10、20、50、100条。切换每页条数返回第1页；上下页在边界禁用。跳页只接受1至总页数内的整数，非法输入恢复当前页码。页面显示总条数及当前展示范围。

保存后结果减少时，当前页不得超过新的总页数，必要时回到最后一个有效页。分页或提交查询后，列表滚动到顶部。

### 6.3 勾选与范围

每行可独立勾选；表头全选只控制当前页，部分勾选时显示半选。无记录时全选禁用。

同一查询条件下，翻页和切换每页条数保留跨页勾选。重新查询或重置清空勾选。编辑后不再满足当前筛选的记录应从选择集合移除，避免导出隐藏的旧选择。

### 6.4 编辑与保存

点击编辑打开“编辑费用指令”弹窗，回填全部业务字段。费用代码只读，其余字段按第5节规则编辑。

保存流程：

1. 对名称、单位和描述去除首尾空格，校验必填项与数值。
2. 与原记录对比，提取实际变化的字段。
3. 无变化时关闭弹窗，提示“未修改费用指令”，不生成日志。
4. 将更新记录与对应日志一并保存。成功后关闭弹窗，刷新列表并提示保存成功。
5. 保存失败时保留弹窗和输入，展示错误，列表及日志保持原值。

取消、关闭按钮及Esc均关闭弹窗，未保存内容不生效。弹窗支持Tab焦点在内部循环，关闭后焦点返回触发入口。当前不提供未保存修改的二次离开确认。

### 6.5 启用与停用

启停通过编辑弹窗中的状态字段完成，不额外增加行内开关。停用项目仍可查询、导出、查看日志和重新启用。

停用项目应从后续新增费用的可选目录中移除。字典修改不应自动删除已提交业务指令或费用明细。对已打开表单及未提交草稿的生效规则，见第10节。

### 6.6 变更日志

每行日志入口只展示该项目记录，按时间倒序排列。弹窗展示项目名称、代码、操作人、时间，以及变化字段的修改前值与修改后值。空值显示占位符，多行描述保留换行。

名称、类型、单位、单价、成本、币种、状态、描述的有效变化均记录。同次保存修改多个字段，形成一条编辑事件，事件内分字段展示。无修改和保存失败不生成日志。

无记录时展示“暂无操作日志”，并说明保存修改后会记录变更内容。

### 6.7 导出

无勾选时导出当前筛选的全部结果；有勾选时只导出当前筛选内的所选项目，包含跨页选择，不限当前页。

导出为带BOM的UTF-8 CSV，文件名为“指令管理_日期.csv”。字段包含费用ID及全部业务字段。隐藏列不影响导出字段；币种输出中文名称。逗号、引号和换行正确转义，可能被表格软件识别为公式的文本按普通文本处理。

导出完成提示范围与实际条数，不修改项目，也不生成编辑日志。当前CSV数值不保证两位小数的显示格式，以数值一致为准。

### 6.8 列设置

可显示或隐藏费用代码至描述，复选框列和操作列不纳入设置。至少保留一个业务列，最后一列不能取消。恢复默认后显示全部业务列。

偏好保存在当前浏览器，刷新后恢复；偏好写入失败时，本次访问仍可切换显示列。点击面板外或按Esc关闭设置面板。

## 7 关联模块约定

### 7.1 暂存管理下单

新增费用读取启用目录，选择后带入代码、名称、类型、单位、计费单价、币种和指令说明。数量及本次业务备注由下单人员填写。

字典与业务费用明细分别保存：字典定义可选项目和默认值；明细保留本次实际采用的单价、数量、汇率及备注。后续字典调价不应直接覆盖已保存明细的金额。

当前关联页面还有补充仓库费用目录，尚未全部归本模块维护；不能认为弹窗中每个费用选项均可在此编辑。目录统一方案需评审确认。

### 7.2 指令详情费用维护

新增费用复用同一启用目录。字典修改在后续重新读取目录时生效，当前没有跨用户及已打开页面的实时广播更新。

成本用于内部参考，不能替代计费单价作为对客收费。关联费用编辑包含成本参考的读取，成本查看范围与生产权限需确认。

### 7.3 业务指令状态边界

字典的“启用、停用”与业务指令的“待确认、已下单、处理中、已完成、驳回、取消”是两套不同状态。

本次已确定的关联规则：指令列表移除“已确认”；“已推送海外仓”改为“已下单”；待确认支持批量下单和批量驳回；已下单不支持取消下单。编辑或停用费用字典不能绕过上述业务规则。

## 8 数据与异常要求

### 8.1 当前原型边界

记录及日志保存在浏览器本地，刷新可恢复；当前没有服务端共享、多用户一致性和跨设备同步。清除浏览器数据、切换浏览器或更换访问源后，不能承诺读取原配置。

未读取到合法数据时回退初始示例；列偏好不可读取时恢复默认。此行为用于原型容错，不等同于生产数据恢复机制。

### 8.2 异常处理

| 场景 | 页面反馈 | 数据结果 |
| --- | --- | --- |
| 必填缺失或仅空格 | 保留表单，提示补全 | 不保存、不生成日志 |
| 单价负数或无效 | 提示须为大于或等于0的数字 | 原记录不变 |
| 本地保存失败 | 提示存储不足或不可用，可修正后重试 | 草稿保留，列表和日志不更新 |
| 查询无结果 | 空态及重置入口 | 不清除已保存费用数据 |
| 无日志 | 明确显示空态 | 不伪造初始化日志 |
| 列偏好写入失败 | 本次切换仍可使用 | 不影响费用记录保存 |

### 8.3 上线建议

由服务端持久化字典和日志，记录真实操作者；费用代码唯一并保留稳定ID；采用记录版本避免多人覆盖；费用更新及日志写入处于同一事务。普通用户不应编辑审计记录。

前端校验需在服务端再次执行。生产接口失败不能静默使用示例价格继续下单。接口、权限和并发方案尚需设计，本文不虚构已实现的接口地址与响应耗时承诺。

## 9 验收标准

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| AC01 | 菜单及直接链接 | 子菜单顺序正确，直接进入可打开页面并展开菜单组 |
| AC02 | 代码查询 | 忽略首尾空格和大小写，包含匹配；提交后才生效 |
| AC03 | 组合筛选及重置 | 类型、状态精确匹配并取交集；重置回第1页、清空选择 |
| AC04 | 空结果 | 总数为0，展示空态，导出禁用 |
| AC05 | 分页 | 支持四种条数；非法跳页恢复当前页，边界按钮禁用 |
| AC06 | 跨页选择 | 全选仅当前页；翻页保留选择，重新查询清空 |
| AC07 | 编辑校验 | 代码只读；必填、长度、金额按字段定义校验 |
| AC08 | 保存成功 | 新值刷新后保留，一次保存生成一条包含多字段的日志 |
| AC09 | 无修改保存 | 关闭并提示未修改，不新增日志 |
| AC10 | 保存失败 | 保留草稿，原列表和日志不变 |
| AC11 | 编辑影响筛选 | 不符合条件的记录移出结果及选择，分页不越界 |
| AC12 | 启停联动 | 停用项目仍可查询，后续新增费用不可选；重新启用后可选 |
| AC13 | 历史金额 | 字典调价不直接覆盖已保存业务明细 |
| AC14 | 日志 | 限当前项目、时间倒序、前后值完整，无记录有空态 |
| AC15 | 导出范围 | 无选择导出全部筛选结果；有选择仅跨页所选，条数一致 |
| AC16 | 导出内容 | 完整字段及ID、中文正常、转义正确、公式型文本按文本打开 |
| AC17 | 列设置 | 支持隐藏和恢复默认，刷新记忆，至少保留一列 |
| AC18 | 键盘交互 | Esc关闭，Tab在弹窗内循环，关闭后返回入口焦点 |
| AC19 | 费用目录 | 字典修改启用项目单价、币种后，重新选择可读取新配置 |
| AC20 | 模块边界 | 费用配置不新增业务下单入口；已下单不存在取消下单操作 |

## 10 评审待确认事项

1. **权限与成本可见性**：哪些角色可查看成本、编辑价格、启停、导出？是否单独授权成本字段？
2. **币种文案及精度**：是否移除单价列名中的“元”？是否严格限制两位小数？输入步长与列表格式不能代替完整金额规范。
3. **零价**：允许0单价是否仅限原型？生产初始化价格如何确认，零价下单是否需要提示？
4. **草稿生效**：调价或停用后，已打开且未提交的表单保留快照还是重新校验？建议已提交明细保留快照，未提交草稿在提交时检查状态并明确提示。
5. **补充费用目录**：是否全部归本模块维护？需明确唯一配置来源，避免同代码存在两处可覆盖的配置。
6. **汇率来源**：当前部分费用使用固定演示汇率，不属于本模块的汇率管理能力；生产汇率来源、责任人及生效时点需另行确定。
7. **扩展范围**：未来是否新增项目、代码如何生成、调价是否审批？未确认前不扩大本期范围。
